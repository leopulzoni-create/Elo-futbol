# Trabajo en este repositorio

- GitHub es la fuente de referencia: el usuario trabaja desde varias computadoras.
- Antes de empezar cambios, consultar y descargar la última versión de `origin/dev`, revisar las diferencias e integrarlas sin perder trabajo local.
- Trabajar en `dev`. Antes de publicar, volver a verificar la rama remota e integrar cualquier actualización; nunca forzar el push ni reemplazar cambios de otra computadora.
- Pedir confirmación al usuario antes de publicar cambios nuevos. Una autorización explícita de subir el cambio permite completar su integración, pruebas, commit y push.
- El generador de equipos sólo lee ELO para calcular variantes; no debe escribir valores ni historial ELO.
